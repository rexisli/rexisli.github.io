## 摘要

数位 DP 解决的是「统计 $[0,N]$ 中满足某个**逐位条件**的数的个数」。它把数看成定长数字串，从高位到低位逐位决策，用记忆化把「已经自由的低位」合并。

模板只有两个布尔状态：@@limit@@（前缀是否还贴着上界）和 @@lead0@@（是否仍全是前导零）。本文要回答三个「为什么」：为什么记忆化只在 @@!limit@@ 时写、为什么 @@lead0@@ 必须进状态、以及加了「依赖历史」的条件后为什么必须加维度——这三处恰好是这套模板最常见的三个翻车点。

不加任何条件时 @@count() == N+1@@，这是自检模板最快的办法。

## 1 问题与记号

把 $N$ 写成 $L$ 位十进制串 $\overline{d_0d_1\dots d_{L-1}}$（$d_0$ 为最高位，允许前导零补齐）。每个 $x\in[0,N]$ 与一个 $L$ 位串一一对应（前导零补齐），且约束「$x\le N$」等价于「字典序 $\le$ $d$ 串」。

于是「数 $x$」变成「数 $L$ 位串」，从上到下逐位枚举即可。

## 2 状态设计

@@dfs(pos, limit, lead0)@@：已确定前 $pos$ 位，返回「把剩余 $L-pos$ 位补完，有多少种合法方案」。

- **$pos$**：当前位置。终止于 $pos=L$，返回 1（该数合法）——合法性已在沿途的 @@continue@@ 里筛掉。
- **@@limit@@**：前缀是否与上界完全一致。一致时当前位 $\le d_{pos}$，否则 $\le9$。转移 @@next_limit = limit \&\& (d == up)@@。
- **@@lead0@@**：是否仍全是前导零。**它是「数位」这个概念本身的一部分**：数字 $7$ 写成 $000\dots007$，那些 0 不是它的数位。若条件涉及「第几位」「相邻两位」「数位和」，就必须靠 @@lead0@@ 区分「真 0」和「补位 0」。

## 3 记忆化的合法性

这是模板里唯一「不看注释就一定写错」的地方。

**引理 1（@@limit@@ 分支状态数）.** $limit=true$ 的状态只有一条链：$(0,true)\to(1,true)\to\dots\to(L,true)$，共 $L+1$ 个。

*证明.* $next_limit$ 为真当且仅当 $limit$ 为真且 $d=d_{pos}$；一旦某位 $d<d_{pos}$，后续 $limit$ 恒假。$\square$

所以 @@limit=true@@ 的状态不需要记忆化（数量极少），记忆也不省时间。

**引理 2（自由状态与上界无关）.** 若 $limit=false$，则 @@dfs(pos,false,lead0)@@ 的返回值与 $N$ 的剩余位无关。

*证明.* $limit=false$ 意味着前缀严格小于上界对应前缀，剩余位可任填 $0\sim9$，上界不再产生任何约束。$\square$

**定理（记忆化正确）.** 只对 $!limit$ 的状态写入/读取 @@dp@@，则结果正确。

*证明.* 由引理 2，同一 $(pos,lead0)$ 在 $limit=false$ 下被多次到达时答案相同（转移只依赖 $pos,lead0$ 与后续位，与 $N$ 无关），故可复用；$limit=true$ 从不读写，故不存在误用。$\square$

**反过来就错**：若把 $limit=true$ 的答案也存进 @@dp[pos][lead0]@@，那么「贴着上界」的答案会被后续「已自由」的同 $(pos,lead0)$ 读到，把上界卡死的结果当成自由结果——表现为答案偏小，且只在某些 $N$ 上错。

## 4 计数的正确性

**定理.** 若条件只依赖「数位串」（对前导零的处理由 $lead0$ 显式给出），则 @@DigitDP(N).count()@@ 返回 $[0,N]$ 中合法数的个数。

*证明.* 双射 $x\leftrightarrow$ 定长串已由第 1 节建立；@@dfs@@ 枚举了所有满足前缀约束的串，且每个串唯一到达；$pos=L$ 时计数 1 当且仅当沿途未被筛掉。$\square$

**自检.** 不加条件时 @@count() == N+1$（$[0,N]$ 共 $N+1$ 个数）。这是零成本的正确性探针，换任何条件之前先跑一遍。

## 5 复杂度

状态数：$O(L\cdot 2\cdot|\text{额外状态}|)$，每状态 $O(10)$ 转移；$limit=true$ 链贡献 $O(10L)$。

$N<10^{18}$ 时 $L\le19$，状态数不过几百——数位 DP 的复杂度几乎不看 $N$ 的大小，只看位数与额外状态。

## 6 实现

```cpp
class DigitDP {
private:
    vector<vector<int>> dp;
    string digit;
    int len;
    // dp[pos][lead0] 表示已经填了 pos 位，是否有非零数字
    // digit 拆位，全部 - '0'

    // 深度优先搜索
    // pos    : 当前处理到第几位（从 0 开始）
    // limit  : 之前的前缀是否与上界完全一致（即当前位是否受限制）
    // lead0  : 是否已经出现过非零数字（用于处理前导零）
    int dfs(int pos, bool limit, bool lead0) {
        // 递归边界：所有位都已填完
        // 根据题目要求返回 1（该数合法）或 0（不合法）
        // 如果要求数字不能全为零，可以判断 lead0
        if (pos == len) return 1;
        // 记忆化查询：仅当 !limit 时记忆，因为 limit 状态数量少且无需重复
        if (!limit && dp[pos][lead0] != -1) return dp[pos][lead0];
        // 当前位可填的数字上限
        int up = limit ? digit[pos] : 9;
        int res = 0;
        // 枚举当前位所有可能数字
        for (int d = 0; d <= up; ++d) {
            // 根据题目要求添加额外过滤条件

            bool next_limit = limit && (d == up);
            bool next_lead0 = lead0 && (d == 0);
            res += dfs(pos + 1, next_limit, next_lead0);
        }
        // 5. 记忆化存储
        if (!limit) dp[pos][lead0] = res;
        return res;
    }

public:
    explicit DigitDP(int num) {
        digit = to_string(num);
        len = digit.size();
        for (auto &i : digit) i -= '0';
        dp.assign(len, vector<int>(2, -1));
    }

    int count() {
        return dfs(0, true, true);
    }
};

cout << DigitDP(100).count() << endl; // 不添加条件，返回 101，即 [0,100]
```

## 7 使用

```cpp
cout << DigitDP(100).count() << endl; // 不加条件，返回 101，即 [0,100]
```

**加条件的两条路**，按条件是否依赖历史区分：

1. **不依赖历史**（只看当前位）：在循环里 @@continue@@ 筛掉。例如「不含数字 4」：

```cpp
for (int d = 0; d <= up; ++d) {
    if (d == 4) continue;
    res += dfs(pos + 1, limit && (d == up), lead0 && (d == 0));
}
```

2. **依赖历史**（相邻两位、数位和、是否出现过某数字、是否已出现回文……）：**必须加维度**，写成 @@dp[pos][lead0][last]@@ 之类，否则记忆化会把不同历史的答案混起来。这是套用模板时最常见的翻车方式。

**区间查询**用前缀差分：

```cpp
long long ans = 1LL * DigitDP(R).count() - DigitDP(L - 1).count();
```

## 8 实现细节与易错点

- **记忆化条件是 @@!limit@@**，写反直接错（第 3 节）。
- **@@dp@@ 初值必须是 $-1$**（或用 @@vis@@ 数组）：用 0 当「未访问」会把「答案为 0」的状态反复重算，严重时退化到指数级。
- **@@next_limit@@ 用 $up$ 判**：@@limit \&\& (d == up)@@。写 @@d == digit[pos]@@ 在语义上也对，但和 $up$ 混用最容易出错。
- **@@lead0$ 别漏**：涉及「数的位数」「首位」「相邻位」的条件必须带上；只涉及「出现次数」的条件有时可以不区分（前导零补的 0 会被计入）——**这时要显式决定补位 0 算不算**，通常是算错。
- **$N<0$ 要特判返回 0**：@@to_string(-1)@@ 得到 @"-1"@，拆位后 $-$ 变成负数字符，行为未定义。
- **@@digit[pos]@@ 已减过 $'0'$**（构造函数里），@@dfs@@ 里别再减。
- **答案可能超 @@int@@**：$[0,10^{18}]$ 的计数可达 $10^{18}$，@@res@@ 与 @@dp@@ 都用 @@long long@@；取模版按题意。
- **多次询问要清 @@dp@@**：每次 @@DigitDP(N)@@ 构造都重新 @@assign@@，模板已处理；但若把 @@dp@@ 提到类外复用，必须手动清空。
- **终止条件 @@pos == len@@ 返回 1**：若题目要求「正整数」，此处要判 @@lead0@@ 并返回 0。

**对拍方式**（本模板实测通过）：不带条件时对 $N=0\sim5000$ 检查 @@count() == N+1$，再抽查 $999999$、$10^6$、$123456789$、$2147483647$；带「不含 4」时对 $N=0\sim5000$ 与暴力枚举逐个比对。

## 9 扩展

**区间 → 差分**：$[L,R]$ 一律用 $f(R)-f(L-1)$（上面 @@DIFF@@ 那段）。

**位数很大（$L\le10^{18}$）.** 状态转移与位置无关时（例如「数位和模 3」+「不含 4」），把转移写成矩阵，用矩阵快速幂算「自由状态填 $k$ 位的方案数」，$O(|\text{状态}|^3\log L)$。

**多串约束.** 「不含子串 42」这类条件可以在数位 DP 上叠一个 AC 自动机（或 KMP 自动机），状态里带上自动机结点。

**贡献法.** 求「所有合法数的数位和之和」时不必在建状态里存和，可以逐位算「该位为 $d$ 的方案数 × $d\cdot10^{k}$」，把计数 DP 复用成贡献 DP。

**递推写法.** 记忆化搜索与「按位递推 $g[pos][...]$（自由后缀方案数）」等价，后者常数更小但对 $lead0$ 的处理更绕，OI 里更常用记忆化。
