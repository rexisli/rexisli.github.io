## 摘要

多重背包的朴素做法是「把 $c_i$ 件物品摊成 $c_i$ 个 0/1 物品」，复杂度 $O\!\left(V\sum c_i\right)$，$c_i$ 一大就废。**二进制拆分**把每类物品压成 $O(\log c_i)$ 个「块」：块大小为 $1,2,4,\dots,2^{k-1},r$，每块整体当一件 0/1 物品。

它成立的唯一原因是一条数论事实：这串块能**恰好**表示 $0\sim c$ 的每个整数。本文给出这条引理的证明、块数上界、与原问题最优解的等价性论证，以及那个把 $c$ 减成负数、直接 @@std::bad_alloc@@ 的手抄笔误。

## 1 问题与记号

$n$ 类物品，第 $i$ 类：单件体积 $w_i$、价值 $v_i$、数量上限 $c_i$；背包容量 $V$。求 $\sum_i w_ix_i\le V,\ 0\le x_i\le c_i$ 下 $\max\sum_i v_ix_i$。

## 2 朴素拆分的代价

拆成 $\sum_i c_i$ 件 0/1 物品，做 0/1 背包：$O\!\left(V\sum_i c_i\right)$。$c_i\sim V$ 时退化为 $O(nV^2)$。

## 3 二进制拆分引理

把 $c$ 写成

$$c=\underbrace{1+2+4+\dots+2^{k-1}}_{2^k-1}+r,\qquad 0\le r<2^k,$$

其中 $k=\lfloor\log_2 c\rfloor$（当 $r=0$ 时最后一块不产生）。块集合 $B=\{1,2,\dots,2^{k-1},r\}$（$r>0$ 时）。

**引理 1（可表示性）.** 对任意整数 $x\in[0,c]$，存在 $B$ 的子集其元素和等于 $x$；且 $B$ 的任何子集和都 $\le c$。

*证明.* 先证「$\le c$ 都能表示」。若 $x\le 2^k-1$，用二进制展开即可（$1,2,\dots,2^{k-1}$ 是「二进制基底」，能表示 $[0,2^k-1]$ 的一切）。若 $x>2^k-1$，取 $x'=x-r\in[2^k-1+1-r,\ c-r]=[2^k-r,\ 2^k-1]$，注意 $r<2^k$ 保证区间非空且 $x'\le 2^k-1$，于是 $x'$ 可表示，再加 $r$ 得 $x$。

上界：所有块和恰为 $c$，子集和自然 $\le c$。$\square$

**引理 2（块数）.** 块数为 $\lceil\log_2(c+1)\rceil$。

*证明.* 块数 $k+[r>0]$。若 $c=2^{k+1}-1$ 则 $r=0$，块数 $k+1=\lceil\log_2(c+1)\rceil$；否则 $\lceil\log_2(c+1)\rceil=k+1$，块数同为 $k+1$。$\square$

**定理（等价性）.** 拆分后的 0/1 背包最优值等于原多重背包最优值。

*证明.* 两个方向：

- 任意多重解 $(x_i)$ 由引理 1 表示为块子集，得到等体积等价值的 0/1 解，故 0/1 最优 $\ge$ 多重最优；
- 任意 0/1 解给出件数 $x_i=\sum_{\text{块}\in S_i}\text{大小}\le c_i$（引理 1 上界），故 多重最优 $\ge$ 0/1 最优。

$\square$

注意这里的关键：**块是可加的整体**——选一块就是选「若干件同种物品」，因为同种物品每件的 $(w_i,v_i)$ 相同，所以体积与价值都按块大小线性放大。若物品之间有别的约束（例如「买 3 件打折」），这条路就不通了。

## 4 复杂度

$$O\!\left(V\sum_i\lceil\log_2(c_i+1)\rceil\right).$$

$n=100,\ c_i=1000,\ V=10^5$ 时：朴素 $10^{10}$，拆分后约 $10^5\times10^3=10^8$ 级别，实际是 $10^5\times(100\times10)=10^8$。

## 5 实现：拆分

```cpp
vector<vector<pair<int, int>>> bags(n + 1);
for (int i = 1; i <= n; i++) {
    int w, v, c;
    cin >> w >> v >> c;
    int base = 1;
    while (c) {
        int t = min(base, c);
        bags[i].emplace_back(t * w, t * v);  // first=体积, second=价值
        c -= t;                              // ← 注意是减去「件数」，不是 t * w
        base <<= 1;
    }
}
```

## 6 实现：0/1 背包

```cpp
// V 为背包容量
vector<long long> f(V + 1, 0);
for (int i = 1; i <= n; i++) {
    for (auto &[w2, v2] : bags[i]) {
        for (int j = V; j >= w2; j--) {
            f[j] = max(f[j], f[j - w2] + v2);
        }
    }
}
cout << f[V] << endl;
```

内层 $j$ **必须倒序**：这是 0/1 背包「每件只用一次」的唯一保证。正序会退化成完全背包。

## 7 实现细节与易错点

- **@@c -= t;@@ 不能写成 @@c -= t * w;@@**。原笔记就是这里手抄错了：$c$ 变成负数后 @@while (c)@@ 对负数仍为真（非零即真），$t=\min(\text{base},c)$ 取到负数，块大小乘出负体积，块无限增加——实测直接 @@std::bad_alloc@@ 爆内存。减的是**件数**，不是体积。
- **块的体积、价值都要乘块大小**：@@t * w@@ 与 @@t * v@@，只乘一个是「体积按块、价值按件」的诡异混合。
- **$r=0$ 时不产生空块**：@@while (c)@@ 天然处理（$c$ 减到 0 就退出），别另外补一块 0。
- **@@bags@@ 开 $n+1$** 是为了 1-based，循环里别混用 0-based。
- **答案用 @@long long@@**：$V\cdot v_i$ 可超 @@int@@。
- **$j$ 倒序**（见第 6 节）。
- **$V$ 很大而 $\sum c_i$ 很小时**，朴素拆分反而更快——两种写法都留一份，按数据选。
- **价值可以为负或体积为 0** 时 0/1 背包的单调性论证失效，需要单独处理（例如体积 0 的物品直接加价值）。

## 8 扩展

**单调队列优化（$O(nV)$）.** 把 $f[j]$ 按 $j\bmod w_i$ 分成 $w_i$ 条链，每条链上做「长度 $\le c_i$ 的滑动窗口最大值」。与拆分法的选择：$V$ 大、$c_i$ 也大时用单调队列；数据小或想少写 bug 时用拆分。

**可行性判定用 bitset.** 只问「能否凑出体积 $j$」时，$\mathrm{bits} \mathrel{|}= \mathrm{bits}\ll(t w_i)$ 比循环快一个量级。

**多重背包的拆分上限优化.** 若两类物品完全相同可合并；若 $c_i\ge \lfloor V/w_i\rfloor$，则该物品等价于完全背包（贪心选择），块数可截断到 $\lfloor V/w_i\rfloor$。

**与「恰好装满」的配合.** 把 $f$ 初值设为 $-\infty$、$f[0]=0$ 即得「恰好」语义；本文是「至多」语义（初值全 0）。
