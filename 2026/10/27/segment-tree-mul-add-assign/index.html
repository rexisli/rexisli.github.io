线段树（区间乘、区间加、区间赋值）

摘要

上一篇里「区间加」与「区间赋值」可以合并成仿射映射 x↦αx+βx \mapsto \alpha x + \betax↦αx+β，其中 α∈{0,1}\alpha \in \{0,1\}α∈{0,1}。本文把 α\alphaα 放开到任意整数，于是区间乘也进来了：三种操作 x↦x+vx\mapsto x+vx↦x+v、x↦vxx\mapsto vxx↦vx、x↦vx\mapsto vx↦v 生成的变换族恰是全体整系数仿射映射

A={ f(x)=αx+β  ∣  α,β∈Z },\mathcal{A} = \{\, f(x) = \alpha x + \beta \;|\; \alpha, \beta \in \mathbb{Z} \,\}, A={f(x)=αx+β∣α,β∈Z},

而 A\mathcal{A}A 对复合封闭（引理 1）。这就是「三个懒标记可以压成两个」的全部理由。剩下的工作只有一件：把复合规则推对，尤其是复合顺序——顺序错了，单看每个 apply_* 都对，结果全错。

  • Mul(l,r,v)\mathrm{Mul}(l,r,v)Mul(l,r,v)：ai←v⋅aia_i \leftarrow v \cdot a_iai​←v⋅ai​

之所以能把三者统一，是因为它们都是对单个元素的一次仿射变换，因此可以在结点上沉积。

2 变换族与封闭性

定义 Aff(α,β):x↦αx+β\mathrm{Aff}(\alpha,\beta): x \mapsto \alpha x + \betaAff(α,β):x↦αx+β。于是

  • Add(v)=Aff(1,v)\mathrm{Add}(v) = \mathrm{Aff}(1, v)Add(v)=Aff(1,v)
  • Mul(v)=Aff(v,0)\mathrm{Mul}(v) = \mathrm{Aff}(v, 0)Mul(v)=Aff(v,0)
  • Assign(v)=Aff(0,v)\mathrm{Assign}(v) = \mathrm{Aff}(0, v)Assign(v)=Aff(0,v)

引理 1（复合封闭）. Aff(α2,β2)∘Aff(α1,β1)=Aff(α2α1,  α2β1+β2)\mathrm{Aff}(\alpha_2,\beta_2) \circ \mathrm{Aff}(\alpha_1,\beta_1) = \mathrm{Aff}(\alpha_2\alpha_1,\; \alpha_2\beta_1+\beta_2)Aff(α2​,β2​)∘Aff(α1​,β1​)=Aff(α2​α1​,α2​β1​+β2​)。

证明. 直接代入：α2(α1x+β1)+β2=(α2α1)x+(α2β1+β2)\alpha_2(\alpha_1 x+\beta_1)+\beta_2 = (\alpha_2\alpha_1)x + (\alpha_2\beta_1+\beta_2)α2​(α1​x+β1​)+β2​=(α2​α1​)x+(α2​β1​+β2​)。□\square□

推论 2. 任意有限长的操作序列都等价于一个 Aff\mathrm{Aff}Aff，因此结点上只需存一对 (α,β)(\alpha,\beta)(α,β)，与操作次数无关。

注意：A\mathcal{A}A 对复合构成半群（有结合律、有单位元 Aff(1,0)\mathrm{Aff}(1,0)Aff(1,0)），但不是群——Aff(0,v)\mathrm{Aff}(0,v)Aff(0,v)（赋值）不可逆。这一点有两处后果：

  1. 复合方向不能随便交换，Aff(0,v)∘Aff(u,0)≠Aff(u,0)∘Aff(0,v)\mathrm{Aff}(0,v)\circ\mathrm{Aff}(u,0) \ne \mathrm{Aff}(u,0)\circ\mathrm{Aff}(0,v)Aff(0,v)∘Aff(u,0)=Aff(u,0)∘Aff(0,v)；
  2. 一旦出现赋值，之前所有的乘加历史都被抹平，可以被「吸收」进一个常数。

3 标记的规范形

代码里存了四个字段：is_assign、lazy_assign、lazy_mul、lazy_add。它表示的映射是

fu(x)  =  mu⋅( is_assignu  ?  su:x )  +  du.f_{u}(x) \;=\; m_u \cdot \bigl(\,\text{is\_assign}_u \;?\; s_u : x\,\bigr) \;+\; d_u . fu​(x)=mu​⋅(is_assignu​?su​:x)+du​.

也就是说，语义顺序固定为：先看是否有赋值把它变成常数，再乘 mmm，最后加 ddd。

引理 3（规范形可维持）. 若 is_assign=1\text{is\_assign}=1is_assign=1 时强制 m=1,d=0m=1, d=0m=1,d=0，则引理 1 的三种复合结果仍落在规范形内。

证明. 分情况看三种 apply：

  • 赋值 Aff(0,v)\mathrm{Aff}(0,v)Aff(0,v) 复合在左：0⋅(⋯ )+v⇒(s,d,m):=(v,0,1)0\cdot(\cdots)+v \Rightarrow (s,d,m) := (v,0,1)0⋅(⋯)+v⇒(s,d,m):=(v,0,1)，进入赋值分支，规范；
  • 乘 vvv：作用于 fff 得 v⋅fv\cdot fv⋅f。若原为赋值分支，v⋅sv\cdot sv⋅s 仍是常数，规范；否则 (m,d):=(vm,vd)(m,d):=(vm, vd)(m,d):=(vm,vd)；
  • 加 vvv：作用于 fff 得 f+vf+vf+v。若原为赋值分支，s+vs+vs+v 仍是常数，规范；否则 d:=d+vd := d+vd:=d+v。

三种情况都保持「赋值时 m=1,d=0m=1,d=0m=1,d=0」或「非赋值时 sss 无意义」。□\square□

这就是代码里 apply_add 里那个看起来多余的 if (is_assign) lazy_assign += val; else lazy_add += val; —— 它不是优化，是规范形的维护。同理 apply_mul 里赋值时只乘 lazy_assign。

4 复合顺序：最容易错的地方

设结点上已有标记 fff，现在要施加新操作 ggg。新操作在时间上更晚，所以新的合成映射是 g∘fg \circ fg∘f（先 fff 后 ggg）。把 ggg 按上面的顺序逐层「套」到 (s,m,d)(s,m,d)(s,m,d) 上：

  1. g=Assign(v)g=\mathrm{Assign}(v)g=Assign(v)：g∘fg\circ fg∘f 是常函数 vvv，直接重置三元组为 (v,0,1)(v,0,1)(v,0,1)；
  2. g=Mul(v)g=\mathrm{Mul}(v)g=Mul(v)：v⋅(m(⋯ )+d)=(vm)(⋯ )+vdv\cdot\bigl(m(\cdots)+d\bigr) = (vm)(\cdots) + vdv⋅(m(⋯)+d)=(vm)(⋯)+vd，即 m←vm,  d←vdm \leftarrow vm,\; d\leftarrow vdm←vm,d←vd；
  3. g=Add(v)g=\mathrm{Add}(v)g=Add(v)：m(⋯ )+d+vm(\cdots)+d+vm(⋯)+d+v，即 d←d+vd \leftarrow d+vd←d+v。

引理 4（下传顺序）. push_down 必须先下传赋值、再下传乘、最后下传加，才能与上面的语义顺序一致。

证明. 若顺序反过来（先加后乘），施加到儿子上的映射是 x↦(x+d)mx \mapsto (x+d)mx↦(x+d)m，而正确语义是 x↦mx+dx\mapsto mx+dx↦mx+d，二者相差 dm−ddm-ddm−d，仅在 d=0d=0d=0 或 m=1m=1m=1 时偶然相等。□\square□

这条引理的实用版本就是一句口诀：写进标记的顺序是「先赋值、后乘、再加」，读出来的顺序也必须如此。

6 复杂度

由引理 4（标准分解至多 2log⁡2n2\log_2 n2log2​n 个结点），单次操作 O(log⁡n)O(\log n)O(logn)；每次操作常数次仿射复合。总时间 O((n+m)log⁡n)O((n+m)\log n)O((n+m)logn)，空间 O(mlog⁡n)O(m\log n)O(mlogn)（动态开点）。

需要注意常量本身变大了：一次 push_down 最多做三次 apply，每次都要取模。模运算下这不是零成本，10510^5105 次操作时建议把 int 换成 long long 以省掉中途溢出判断。

9 实现细节与易错点

  • 顺序：push_down 里赋值 → 乘 → 加，一步都不能换位（引理 4）。
  • 赋值要重置乘加：apply_assign 把 lazy_mul 置 1、lazy_add 置 0，否则残留的乘加会在之后被重复施加。
  • 赋值分支不能让 lazy_add 累积：apply_add 在 is_assign 时改的是 lazy_assign，改 lazy_add 会让那个 0 变成非 0，破坏规范形（引理 3）。
  • 取模时机：模 PPP 时 dat、lazy_mul、lazy_add、lazy_assign 都要在写入时取模；尤其 lazy_assign = val % P 必须做，输入可能是负数。
  • 乘法溢出：m⋅datm\cdot \mathrm{dat}m⋅dat 在 P∼109P \sim 10^9P∼109 时可达 101810^{18}1018，用 long long 存中间值；本实现的字段是 int，模数大时要改。
  • 查询也要 push_down：查询只读，但它需要的 dat\mathrm{dat}dat 在更细一层的结点上，不下传就不对。
  • assert(rangeL <= rangeR)：忘了 build 或 reset 就调用会立刻暴露，而不是静默返回错误答案。
  • 不要用「先乘后加」的另一套约定混搭：另一种常见实现把标记写成 x↦(x+d)mx\mapsto (x+d)mx↦(x+d)m（先加后乘），语义顺序相反。两套都自洽，但必须全套统一，混用后果与引理 4 的反例相同。

10 扩展

标记永久化. 不下传，查询时沿路径累积 fff。因为 A\mathcal{A}A 是半群（可结合）但不可交换，累积必须按「从上到下」的顺序乘，实现上比下传更需要小心。

区间赋值 + 区间最值. dat\mathrm{dat}dat 换成 max⁡\maxmax，赋值时 dat←v\mathrm{dat}\leftarrow vdat←v，乘加时按 vvv 的符号讨论（乘负数会把 max⁡\maxmax 变 min⁡\minmin），这时要同时维护 max⁡\maxmax 与 min⁡\minmin。

可持久化. 与单标记情形一样做路径复制；因为标记是 (α,β)(\alpha,\beta)(α,β) 对，复制时只多存两个数。

Beats 类结构. 若把「区间取 min」也塞进来，操作族不再是仿射的（min⁡(x,v)\min(x,v)min(x,v) 不是仿射映射），懒标记的封闭性失效，必须转向 Segment Tree Beats 的势能分析。这是本文框架的边界。
